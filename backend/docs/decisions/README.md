# Architecture decision records

This directory records accepted decisions that constrain more than one MVP
stage. Each record describes a settled direction and its consequences.
Stage-specific choices that still lack evidence remain in the
[roadmap](../../ROADMAP.md) until that stage's entry gate; they are not recorded
here as if already decided.
